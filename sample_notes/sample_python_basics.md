# Sample notes: Python basics
(Made-up demo notes. Replace with your own.)

- A **variable** is a name that refers to a value. `x = 5` makes `x` refer to 5.
- **Lists** are ordered and can change: `nums = [3, 1, 2]`; `nums.append(4)`.
- **Dictionaries** map keys to values: `ages = {"ana": 19}`; `ages["ana"]` gives 19.
- A **for loop** repeats once per item: `for n in nums: print(n)`.
- A **function** packages reusable code: `def area(w, h): return w * h`.
- `==` checks if two values are equal; `=` assigns a value.
- **Indentation** defines code blocks in Python, unlike the braces used in Java.
- An **exception** is an error raised while the program runs; `try`/`except` lets you handle it instead of crashing.
